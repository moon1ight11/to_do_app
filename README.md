# ToDoApp Frontend
Фронтенд для ToDoApp — приложения для управления задачами.

## Запуск
```bash
npm install
npm start

```
Приложение будет доступно на http://localhost:3000.
Бэкенд должен быть запущен на http://localhost:8080.

## Страницы
- /auth — авторизация и регистрация. Переключение между формами с анимированным индикатором.
- / — главная страница со списком задач. Создание и редактирование через bottom sheet. Поддержка подзадач. Кастомные чекбоксы для отметки выполнения. Плавающая кнопка добавления задачи. Нижняя панель навигации.
- /profile — профиль пользователя и настройки временной зоны. Редактирование имени, email и пароля. Удаление аккаунта.
